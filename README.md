# Personal AI Assistant

A modular, local-first personal AI assistant built with Python.

## Planned capabilities

- Text conversation
- Voice conversation
- Persistent conversation history
- Long-term memory
- RAG
- Tool calling
- Personal productivity tools
- Local/open-weight LLM support

## Architecture

The system is designed as modular components:

- API
- Assistant orchestration
- LLM
- Database
- Memory
- RAG
- Tools
- Voice
